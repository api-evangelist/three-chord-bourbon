# Three Chord Bourbon

> Three Chord Bourbon, Inc. is an American whiskey blending house founded in 2017 by Rock & Roll Hall of Fame guitarist, producer and songwriter Neil Giraldo. It blends straight bourbon whiskeys aged a minimum of four years using a process the company calls "Perfectly Tuned Taste," and has extended the line into rye and cask-finished expressions. Product is co-packed at Ugly Dog Distillery in Chelsea, Michigan; the corporate office is in Clarence, New York.

## API surface

Three Chord Bourbon publishes **no public API**. As of 2026-08-30 there is no developer
portal, no API reference, no OpenAPI/Swagger/GraphQL/AsyncAPI contract, no MCP server,
no A2A agent card, no SDK on any public package registry, and no `/.well-known/`
discovery document on either company host. This is a consumer packaged goods company;
the absence is expected and is not a defect.

The only machine-readable endpoint reachable on the domain is `https://threechordbourbon.com/wp-json/`,
the stock WordPress REST API index that ships with the CMS. It is not documented, not
offered to integrators, and is not registered as an API in this profile.
